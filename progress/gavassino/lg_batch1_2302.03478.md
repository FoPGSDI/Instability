### Key Result
**Theorem 1:** Given linearised field equations M^mu_AB d_mu phi^B = -Xi_AB phi^B with a future-directed timelike information current E^mu = (1/2) E^mu_AB phi^A phi^B and entropy production d_mu E^mu = -sigma <= 0, the system is causal and can be rewritten in symmetric-hyperbolic form.

**Universality classes:** Theories are classified by (g0,g1,g2)-(gbar0,gbar1,gbar2), counting SO(3) scalars, vectors, tensors in degrees of freedom and conserved densities. All theories in the same class are equivalent when linearised.

**Key class:** (3,2,1)-(2,1,0) contains IS, BDNK, BRSSS, DNMR, Chapman-Enskog, etc.
